## Intent
Staff can search the bookings list by booking reference as well as by name.

## Acceptance
- Given a booking with a known reference, when staff type that reference in the search, then that booking is found.
- Given a search by name, when staff search, then the results are the same as today.
- Given a reference typed in lower case or with spaces, when staff search, then the booking is still found.
- Given a reference that matches no booking, when staff search, then other bookings are not shown.

## Boundaries
- Must not change the format or length of booking references (IN-9043 waits on a person; IN-4693).
- Must not change name search.

Allowed by AUT-1 (new columns, filters or fields that add to what is there and take nothing away).

## Request
Ticket: the bookings list can only be searched by name. Staff want to search by booking reference too.
