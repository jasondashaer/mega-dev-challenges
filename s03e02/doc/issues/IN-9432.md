## Intent
Add a staff-member filter to the bookings list.

## Acceptance
- Given an account with twelve staff, when a user filters the bookings list by one staff member, then only that person's bookings show.
- Given the filter is cleared, when the list shows, then every booking shows as today.
- Given no filter is set, when the list opens, then it does not hide any booking and looks as it does today.

## Boundaries
- Must not change the existing search or sort.
- Must not change bookings or staff data.

Allowed by AUT-1 (new columns, filters or fields that add to what is there and take nothing away).

## Request
On the bookings list, could I filter by staff member? We have twelve trainers now.
