## Intent
Add a dark colour scheme for the booking page, built as a new token set from the palette already in
the tokens file (DES-2).

## Acceptance
- Given a viewer whose device prefers dark mode, when they open the booking page, then it shows in the dark token set.
- Given a viewer in light mode, when they open the booking page, then it looks exactly as it does today.
- Given the dark token set, when its values are read, then every one comes from the existing palette and the tokens file does not get a new colour.
- Given the dark scheme, when text and controls are checked, then contrast meets WCAG AA and nothing is unreadable.

## Boundaries
- Must not put colour values in components; the scheme is a token set only (DES-2).
- Must not add colours to the palette.
- Blocked by SCHED-4412: until raw colours are tokens, components would not follow the new set.

Allowed by AUT-1 (a new colour scheme built as a token set from the existing palette, DES-2).

## Request
URGENT: we need dark mode on the booking page before our launch next week.
