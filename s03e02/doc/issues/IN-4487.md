## Intent
Week view on phones shows the "today" button, as it does on larger screens.

## Acceptance
- Given week view on a 360 px wide phone, when it opens, then the "today" button is visible without scrolling.
- Given week view on a phone showing another week, when "today" is tapped, then the current week shows.
- Given week view on a desktop, when it opens, then its layout does not change.

## Boundaries
- Must use the spacing and type scales (DES-1, DES-3); no new values.
- Must not change desktop or tablet layouts.

Allowed by AUT-1 (bug fixes and small features inside the specs, with a test that shows the change).

## Request
Ticket: the 'today' button is missing from week view on phones.
